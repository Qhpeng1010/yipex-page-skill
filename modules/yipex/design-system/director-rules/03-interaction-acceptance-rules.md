# YiPex 交互与验收规则

本文件是所有页面共享的交互状态、权限、恢复、响应式、可访问性和验收规则来源。Page Pattern 只补充页面族特有的操作流程；验收规则证明页面是否可用，不限制页面可以承载的新业务能力。

规则等级沿用 `01-visual-constitution.md` 的 `MUST`、`DEFAULT` 与 `HEURISTIC`。

## 任务与状态

**YP-INT-001 `MUST`** 每个关键操作都要定义触发条件、前置条件、处理中状态、成功结果、失败反馈和恢复路径，并映射到 `page.interactions` 与 `page.states`，不得只描述静态外观。

**YP-INT-002 `MUST`** Loading、Empty、Error、Permission Denied、Success 和业务处理中状态必须具有独立语义。局部失败优先保留其他可用内容和上一次有效数据；空数据不能伪装成请求失败，失败也不能伪装成空数据。

**YP-INT-003 `MUST`** 异步提交、查询、导出、重试和危险操作必须阻止重复触发；写操作和重试还必须使用请求层幂等标识或等价业务机制，按钮 Loading 不能代替幂等保护。响应发生竞态时只应用最近一次仍有效的结果。

**YP-INT-004 `DEFAULT`** 筛选条件区分正在编辑的 draft 和已作用于结果的 applied 状态；确认筛选后再刷新受影响区域。查询回到第一页，分页保留 applied 条件，无结果保留查询上下文和必要结构，错误提供重试或修改条件的路径。

**YP-INT-005 `MUST`** 表单提交前完成适用校验，失败时保留输入并定位首个可处理问题；服务端字段错误尽量映射回对应字段，无法定位的错误在表单级反馈。离开 dirty 表单、分步流程或未保存弹层前确认放弃。

## 数据更新与恢复

**YP-INT-006 `DEFAULT`** 首次加载可以使用稳定 Skeleton；后续刷新、筛选、分页、联动和关联区域更新优先局部 Loading，并保留上一次有效数据、布局和当前阅读上下文。局部失败不得无理由替换整个页面。

**YP-INT-007 `MUST`** 自动刷新和后台更新不得打断正在输入的筛选、打开的 Modal/Drawer、未完成表单或进行中的业务操作。冲突时保留用户工作状态，并在安全时机应用或提示新数据。

**YP-INT-008 `MUST`** 写操作成功后必须同步更新受影响的数据、业务状态、可用操作和权限，不保留已经失效的按钮或旧状态。失败时保留用户仍可继续工作的输入、选择和来源上下文。

**YP-INT-009 `DEFAULT`** Modal、Drawer 和独立页面关闭或返回来源后，保留 Contract 声明的筛选、分页、排序、Tab、选择和滚动上下文。多页面任务通过可追踪的 Binding 与 Transition 往返，并使用一个明确入口。

**YP-INT-010 `MUST`** 处理中任务、轮询结果和跨页面业务状态不能只存在内存中；需要跨刷新恢复时使用 URL、业务 ID 或等价持久化标识。轮询必须声明频率、超时、后台切换和终止条件。

## 权限、危险操作与反馈

**YP-INT-011 `MUST`** 危险或不可逆操作在执行前说明对象和影响并要求确认；无权限时不渲染可执行入口，敏感信息不能通过错误、空状态、演示数据或占位内容泄露。

**YP-INT-012 `DEFAULT`** 反馈强度与影响范围一致：轻量成功使用 `message`，区域问题使用局部 `Alert` 或 Error，阻断整个任务时使用页面级结果。跨页面提交成功应在用户到达的目标页面反馈，并按真实排序或业务状态展示结果。

**YP-INT-013 `MUST`** Not Found、Permission Denied、业务不可用和请求失败必须区分。记录不存在时提供返回来源或业务入口；无权限不暴露受限字段；可重试错误提供明确重试路径，不可恢复错误说明下一步。

## 响应式与可访问性

**YP-INT-014 `MUST`** 键盘可以到达主要内容和操作；弹层打开后焦点进入弹层，关闭后回到触发控件；校验失败、异步完成和动态刷新只在必要时移动或播报焦点。被替换的处理中控件消失后，焦点移动到结果标题或下一步操作。

**YP-INT-015 `MUST`** 响应式变化不得造成文字、控件、图表和固定操作区重叠，不得隐藏唯一主操作。表格或可视化需要横向空间时在所属业务区域内部滚动，并保持关键字段和操作可达。

**YP-INT-016 `MUST`** Hover、Active、Selected、Focus、Loading、Disabled 和 Error 等适用状态必须使用官方语义并保持布局稳定。错误、选中、告警、趋势和业务状态不能只依赖颜色；图标操作具有可访问名称。

**YP-INT-017 `MUST`** 表单控件必须有关联 Label、帮助和错误信息。Label 使用 Body 字体且不加粗，字段说明可使用可聚焦帮助图标与 Tooltip，校验错误仍显示在字段附近，不得隐藏在 Tooltip 中。

## MVP 验收证据

**YP-INT-018 `MUST`** 每次交付至少检查：Page Spec 与 Contract 一致；关键操作具有处理中、成功、失败和恢复；声明的状态能在页面中表达；新能力的组件与交互已在 Spec 中声明；实际执行过的检查与待人工验收项被准确记录。

**YP-INT-019 `DEFAULT`** 状态覆盖按页面实际任务选择，不机械要求每页具有全部状态。读取型页面通常覆盖 Loading、Empty、Error 与 Permission Denied；写入型页面增加 Dirty、Validating、Submitting 和 Success；处理中任务增加 Processing、Cancelled 或业务状态。

**YP-INT-020 `DEFAULT`** 默认执行结构、契约、脚本语法和派生产物等轻量静态检查。浏览器、截图、响应式视觉和自动点击只在用户明确要求时执行；未执行的视觉与业务验收不得写成已经通过。

**YP-INT-021 `MUST`** 未命中现有 Pattern 的开放页面与标准页面遵循同一交互、权限、响应式和可访问性底线。`custom` 不是降低质量要求的例外通道。
