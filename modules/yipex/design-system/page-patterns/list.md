# YiPex List Page Pattern

本文件是 `list` 页面族的按需参考，只定义查询、结果列表和上下文操作的特有结构。视觉、载体选择和通用交互分别遵循导演规则 01、02、03。

## 适用范围

- 适用于通过条件查找、浏览、比较和处理一组记录的任务。
- 汇总指标、批量操作、新增入口和详情 Overlay 都是可选区域，不改变主页面族。
- 主要任务是分析趋势时使用 Dashboard Pattern；主要任务是查看单条完整记录时使用 Detail Pattern。

## 推荐骨架

```text
List
├── Page Header (when needed)
├── Summary (optional)
├── Query Region
├── Result Header / Actions
├── Table
├── Pagination
└── Detail / Form Overlay (optional)
```

- 业务内容挂载到固定 Shell 的 `#yipex-page`。
- 查询区与结果区默认使用无外框、无阴影的平面结构，不重复显示无信息增量的区域标题。
- 查询区和结果区使用 Divider 建立层级；汇总只在帮助判断当前结果时出现。

## 查询区

- 使用 Ant Design `Form`、`Input`、`Select` 和 `DatePicker.RangePicker` 等语义组件。
- 桌面默认四列筛选网格；查询/重置作为不可拆分操作组参与最后一个网格位置，存在完整空闲列时放在末行最右侧，空间不足时单独成行。
- 查询使用主按钮，重置使用默认按钮。查询操作组与结果工具区分别维护自己的主次关系。
- 无特殊业务语义时，查询和重置按钮不添加图标。

## 结果区

- 多记录结果默认使用 `Table` 和 `Pagination`；空结果使用 `Empty`。
- 每个业务列声明稳定宽度；文本、状态和时间左对齐，金额与数量右对齐。横向滚动时固定最右侧操作列，并使业务列宽度总和与 `scroll.x` 一致。
- 固定单位写入表头，格式为 `列名 (单位)`；逐行单位不同时才保留行内单位。
- 状态列使用 Badge 状态点加文字；文字操作与操作列表头左对齐。
- 分页统计左对齐，页码右对齐。批量操作只在存在选择能力时出现；导出范围必须明确为已选记录或当前 applied 结果。
- 桌面和超宽屏下，查询区、结果标题、Table 与 Pagination 占满 Shell 内容槽；四列筛选网格随可用宽度均匀分配，不在页面根节点设置固定最大宽度。

## 页面族特有交互

| 交互 | 页面族特有结果 |
| --- | --- |
| 查询 | draft 成为 applied，页码回到第一页，同时刷新列表、汇总和总数 |
| 重置 | 恢复默认条件和默认结果，清除与旧结果绑定的选择 |
| 分页 | 保留 applied 条件，切换结果页并把结果区恢复到可读起点 |
| 选择记录 | 更新选择数量和可用批量操作，移除已失效选择并说明原因 |
| 打开详情 | 保留筛选、分页、排序和选择，在当前上下文打开 02 选择的载体 |
| 导出 | 使用已声明范围生成文件，并反馈导出条数 |

- 记录包含创建时间时默认按创建时间倒序；新增成功后按真实业务排序呈现，不使用持久闪烁或绿色行背景代替成功反馈。
- Table 的选择、排序、分页和行内操作必须键盘可达；可点击整行时仍提供明确详情入口。
- 窄屏保留表格区域内部横向滚动，筛选网格改为单列，操作组跟随最后一个字段。

## 变体

- Query + Table
- Query + Summary + Table
- Query + Table + Detail Overlay
- Query + Table + Form Overlay
