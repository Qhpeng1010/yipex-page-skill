# YiPex Result Page Pattern

本文件是 `result` 页面族的按需参考，只定义成功、失败、处理中和取消结果的特有内容与操作。是否使用结果页遵循导演规则 02，通用状态恢复、幂等和可访问性遵循 03。

## 适用范围

- 适用于提交、审核、支付、导入、批处理等操作结束后的独立反馈页面或关键结果区域。
- 结果页说明发生了什么、当前状态和下一步，不承载新的复杂任务；完整业务对象进入 Detail。

## 推荐骨架

```text
Result
├── Status Icon
├── Title
├── Description
├── Summary / Reference (optional)
└── Primary / Secondary Actions
```

- 使用 Ant Design `Result` 或等价语义组合。
- 标题直接说明结果，Description 补充原因、影响、参考编号或预计完成时间。
- 操作区最多一个主操作；次操作位于主操作左侧。
- 不使用装饰卡片、标签或动效稀释状态和下一步。
- Result 页面外层状态容器占满 Shell 内容槽并在可用高度内居中；标题、说明和操作作为内部阅读单元限制行长，不把页面根节点固定为窄画布。

## 页面族特有交互

| 交互 | 页面族特有结果 |
| --- | --- |
| 返回来源 | 返回发起操作的页面，并按 Contract 决定是否刷新 |
| 查看详情 | 携带业务对象 ID 进入 Detail |
| 再次操作 | 进入新的 Form 或业务页面，不复用上次提交的敏感状态 |
| 重试 | 使用原操作的安全标识重新处理并更新结果状态 |
| 取消处理中任务 | 仅在业务支持时进入 cancelling，完成后更新为 cancelled |

## 状态内容

- Success：说明已完成事项、关键结果和下一步，不继续显示处理中控件。
- Error：说明失败对象和恢复方式；可修改时返回原 Form，可重试时显示重试，不可恢复时提供返回入口。
- Processing：说明正在执行、预计时间以及用户是否可以离开。
- Permission Denied：说明无权执行或查看结果，不暴露受限信息。
- Cancelled：说明任务已取消及影响，仅在业务存在该状态时使用。

- 状态图标同时配合可读标题；参考编号和关键结果允许选择或复制。
- 窄屏允许操作组纵向排列；长错误、参考编号和说明自然换行，Processing 的进度与取消入口保持可见。
