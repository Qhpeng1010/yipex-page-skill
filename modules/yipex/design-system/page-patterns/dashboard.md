# YiPex Dashboard Page Pattern

本文件是 `dashboard` 页面族的按需参考，只定义指标、分析、联动与下钻的特有结构。视觉、载体选择和通用交互分别遵循导演规则 01、02、03。

## 适用范围

- 适用于同时判断指标、趋势、分布、异常和明细的分析任务。
- Pattern 是可裁剪骨架，不要求每个 Dashboard 包含所有区域；Contract 声明实际区域和数据范围。
- 仅用于查找记录时使用 List Pattern；以处理单条记录为主时使用 Detail Pattern。

## 推荐骨架

```text
Dashboard
├── Header / Global Filters / Actions
├── Metrics
├── Analysis Panels
├── Detail or Exception Table (optional)
└── Detail Overlay (optional)
```

- 内容通常按“统计范围 → 核心指标 → 分析区域 → 明细或异常列表”组织。
- 更新时间、统计范围和数据来源等影响判断的信息必须可见；页面操作主次由核心分析任务决定。

## 指标与分析

- 核心指标只回答本页重要经营问题，不把普通字段包装成指标卡。同组指标保持相同结构、对齐和数字格式。
- 对比值说明口径和周期；图表声明标题、单位、统计周期、数据范围和可交互范围。
- 趋势、分布和排行按业务关系组合，不为填满画布添加无意义图表。图表容器使用稳定尺寸。
- Dashboard 根节点占满 Shell 内容槽；大屏下指标网格和分析面板使用全部可用宽度，并通过网格比例组织信息，不把整张看板固定在窄画布中居中。
- 需要进入处理任务时，在分析区后提供明细或异常列表；下钻携带当前筛选和分析范围。

## 页面族特有交互

| 交互 | 页面族特有结果 |
| --- | --- |
| 修改全局筛选 | 所有声明受影响的指标、图表和列表使用同一数据范围刷新 |
| 刷新 | 更新数据和最后更新时间，保持筛选、下钻和用户上下文 |
| 图表筛选 | 显示明确 Selected 状态，并按 Contract 联动相关区域 |
| 清除图表筛选 | 恢复全量分析范围，清除方式保持可发现 |
| 下钻 | 打开携带当前数据范围的明细列表或详情 |
| 导出 | 导出当前筛选与下钻范围，并明确反馈结果 |

- 图表元素只有在提供 Hover、Focus、可读名称和清除方式时才能承担交互。
- 图表提供文字标题、单位、数据摘要或可访问的等价表格；颜色不是趋势、异常或类别的唯一表达。
- 窄屏优先改单栏，指标网格逐级减少列数；图表保持可读尺寸，必要时在分析区域内部滚动或简化次级标签。

## 变体

- Overview：指标 + 趋势 + 分布
- Monitoring：指标 + 实时状态 + 异常列表
- Analysis：全局筛选 + 多分析区域 + 下钻明细
