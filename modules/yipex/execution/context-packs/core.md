# YiPex Core Context

- 需求决定页面功能和信息架构，规范决定视觉表达和交互质量。
- 页面可以是任意页面类型；`metadata.pageType` 使用描述性字符串，不与固定枚举绑定。
- 组件以树形结构表达，组件类型可以使用内置类型，也可以通过 `custom` 和 `extensions` 扩展。
- 所有关键操作都应有明确状态反馈；涉及权限、错误或危险操作时不能只用颜色表达。
- 不确定的业务信息写入 `metadata.assumptions`，不要伪造后端行为。
- 默认业务内容挂载到 `modules/yipex/shell/` 的 `content` 插槽；Shell 外框不属于单页功能实现范围。
- Shell 使用统一的六项默认导航：首页、贸易背景材料、数币钱包流水、法币钱包流水、收款账户、个人中心；导航文字为 `14px` 常规字重，Logo 宽度 `85px`，消息入口不带数字气泡。导航点击非当前项时，内容插槽显示菜单标题和“暂无数据”空状态。
