# Review

## 自动检查

- 两个 Page Spec V2 均通过结构校验。
- 两个预览文件均通过构建和轻量 JavaScript 检查。
- Page Composition 契约通过组合规则校验。

## 功能覆盖

- 商品列表：商品名称、状态筛选，查询、重置、分页和新增入口。
- 状态列：使用 Ant Design Badge 官方语义色，商品状态在 Page Spec 中显式映射为在售 success、草稿 warning、已下架 default。
- 新增商品：基本信息、销售信息、确认提交三步，逐步校验、上一步、取消和提交。
- 提交成功：商品记录写入 localStorage，返回列表，列表显示成功 message 并按创建时间倒序置顶。
