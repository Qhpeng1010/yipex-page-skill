# 外包钱包管理评审记录

## 交付结论

- 使用标准 `list.query-table` Recipe 与 `yipex-standard-query-table-v1` 渲染器生成。
- `page-spec.json` 是页面唯一可编辑源，`preview.html` 为派生产物。
- 页面标题区只显示“外包钱包管理”，没有操作、副标题、场景说明或其他引导文案；“新增钱包”位于钱包列表结果区右侧。
- Shell 导航按需求裁剪为“首页、外包钱包管理”，未展示无关目录。
- 查询、重置、分页、详情和新增全部基于浏览器内 Mock 数据运行，未声明或调用任何后端接口。

## 演示数据边界

- 外包公司、外包人员、币种和钱包记录均为本地演示数据，不代表生产数据范围。
- 新增钱包编号由浏览器本地生成；初始额度作为演示记录的可用余额，冻结金额默认为 0，钱包状态默认为正常。
- 未虚构接口地址、请求方法、权限结果、服务端校验或持久化结果；刷新页面后新增记录不会保留。
