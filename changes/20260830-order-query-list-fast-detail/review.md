# Review

## 自动检查

- Page Spec V2 结构、Page Contract、组件、状态和交互映射通过。
- 标准查询列表预览构建通过，页面根节点和 JavaScript 轻量检查通过。
- 日期范围与详情浮层能力已装配，查询、重置、分页、打开详情和关闭详情均有交互声明。
- 订单金额使用 `amount` 格式，由标准渲染器右对齐；订单状态使用显式 Badge 语义映射。
- 页面标题及结果区未配置或显示“演示数据”标签。
- Shell 导航按需求裁剪为“首页、订单查询”，未展示无关目录。

## 功能覆盖

- 查询条件：订单号、客户名称、订单状态和日期范围。
- 列表字段：订单号、客户、订单金额 (元)、订单状态、支付渠道、下单时间和操作。
- 查看详情：7 项信息使用右侧 Drawer，关闭后保留筛选和分页上下文。
- 重复出现的“客户”字段按一个客户列实现，并已记录为规格假设。
- 页面覆盖 Loading、Empty、Error 和 Permission Denied 状态契约。
