# Proposal

- 需求原文：生成订单查询列表页面。查询条件包括订单号、客户名称、订单状态和日期范围，支持查询、重置、分页和查看详情。表格展示订单号、客户、客户、订单金额(元)、订单状态、支付渠道和下单时间，金额右对齐，不显示演示数据标签。
- 页面目标：帮助订单运营人员按明确条件快速定位订单，并在不离开列表的情况下核对详情。
- 使用角色：订单运营人员。
- 关键操作：查询、重置、分页和查看详情。
- 页面结构：使用 YiPex 标准 Query + Table + Pagination + Detail Overlay 配方；7 项详情信息使用右侧 Drawer。
- 字段处理：重复的“客户”按一个客户列实现；金额列通过金额格式声明自动右对齐。
- 可见标识：页面标题区不展示“演示数据”标签。
