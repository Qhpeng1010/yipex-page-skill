# Page Design

- 页面名称：统一调整为“经营分析”，保留日期筛选、核心指标、销售额趋势、订单状态分布、异常订单列表、导出和详情能力。
- Shell：使用 `modules/yipex/shell/` 的固定顶部栏、左侧导航、内容区和 Footer；业务规格不再绘制侧栏、Logo、用户入口或收起控制。
- 页面结构：内容区依次为 20px 页面标题与演示标签、平面日期筛选区、四项指标、趋势与状态双栏、异常订单列表和详情抽屉。
- 视觉风格：内容区采用 24px 内边距、16px 模块间距、白色平面背景和轻分割线；指标与图表使用 8px 数据卡片，不使用重阴影或装饰性渐变。
- Ant Design：日期、按钮、指标、时间窗切换、输入、表格、分页、标签、空状态、反馈和详情均使用官方 `DatePicker.RangePicker`、`Button`、`Statistic`、`Segmented`、`Input`、`Table`、`Pagination`、`Tag`、`Empty`、`message`、`Drawer`、`Descriptions`、`Alert`、`Timeline`。
- 图表例外：Ant Design 不提供图表组件，销售额趋势使用只读 SVG 折线图，订单状态使用环形图；两者均提供文字标题、数值和图例，不只依赖颜色表达。
- 操作规则：查询使用黑色主按钮；导出保留下载图标以表达工具语义；详情和订单号使用品牌绿文字操作；普通查询、详情和标记操作不附加无必要图标。
- 响应式：指标桌面四列、窄屏两列；分析区在中等宽度改为单列；表格使用 Ant Design 横向滚动；手机端筛选和分页垂直排列。
- 偏离规范的理由：无。后台控件统一采用 Ant Design `middle` 尺寸 32px；图表属于官方组件库未覆盖的业务可视化能力。
