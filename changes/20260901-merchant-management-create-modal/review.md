# 商户管理新增商户评审记录

## 交付结论

- 使用标准 `list.query-table` Recipe 与 `yipex-standard-query-table-v1` 渲染器生成。
- `page-spec.json` 是唯一可编辑源，`preview.html` 为派生产物。
- 根据评审反馈删除了未被需求要求、且没有信息增量的页面副描述；重新生成的预览仅保留页面标题。
- Shell 导航按需求裁剪为“首页、商户管理”，未展示贸易背景、钱包、收款账户或个人中心等无关菜单。
- 新增商户保留列表上下文并固定使用 Ant Design Modal；`preserveStructure: true` 同时声明在页面、数据与新增配置中。
- 未声明或调用任何后端接口。预览中的新增、刷新和文件选择仅作用于浏览器内演示数据。
