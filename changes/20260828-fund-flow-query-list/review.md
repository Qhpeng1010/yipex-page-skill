# Review

## 自动检查

- Page Spec V2 结构与组件/交互引用校验通过。
- 预览文件已由 Page Spec 构建，并通过 JavaScript 语法与页面根节点检查。
- 共享查询列表渲染器的既有页面回归构建通过。

## 待人工验收

- 桌面端四列筛选布局、表格横向滚动与固定操作列是否符合预期。
- 窄屏下筛选单列、分页及两个抽屉的布局与可操作性。
- 新增流水必填校验、提交后插入列表、详情展示与取消订单确认流程。
- loading、empty、error 和 permission-denied 状态的视觉效果。

## 说明

- 页面使用演示数据，新增与取消只在浏览器当前会话生效。
- 取消订单仅对“待处理”流水开放，其余状态的取消按钮禁用。
