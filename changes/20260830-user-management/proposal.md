# Proposal

- 需求原文：生成用户管理查询列表页面。顶部提供用户名、手机号、用户状态、注册时间查询条件，支持查询和重置；下方展示用户列表，字段包括用户名、手机号、角色、状态、注册时间和操作；支持查看详情、编辑和新增用户，新增/编辑保存后返回列表刷新，详情页支持返回列表。
- 页面目标：帮助平台运营人员快速定位用户、核对用户信息、维护用户资料和权限。
- 使用角色：平台运营人员。
- 关键操作：查询、重置、分页、新增用户、编辑用户、查看详情、返回列表。
- 数据边界：全部列表、表单和详情行为使用浏览器内演示数据，不调用或声明后端接口；新增和编辑记录保存在 localStorage。
