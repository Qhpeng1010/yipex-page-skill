# Page Design

- 页面结构：使用 `shell.template.html` 提供顶部栏、左侧导航、工作区和 Footer；业务区只挂载到 `#yipex-page` 内容插槽，依次为页面标题、查询条件区、结果表格和详情抽屉。
- 视觉决策：使用黑色主操作、品牌绿强调、白色表面、8px 圆角和浅灰画布；查询区和表格保持后台密度，便于扫描。页面标题仅显示 20px 主标题和演示标签，不显示副描述。
- 后台查询规范：内容区默认 `24px` 内边距；查询条件与结果列表使用无外框、无阴影的平面容器；查询条件区域不渲染额外标题；查询卡片不额外叠加左右内边距；桌面筛选字段默认四列，查询/重置按钮独占下一行并右对齐，窄屏再降为单列。
- 规格约束：表单、按钮、分页统一使用 Ant Design `middle` 尺寸（32px）；条件区与列表之间使用 Divider Token 的 1px 灰色分割线，分割线上下各 16px，同区域内容间距统一 16px；列表标题下不显示分割线；分页统计左、页码右对齐；可点击字段和列表操作使用品牌绿色。
- 操作按钮：无特殊语义的重置、查询、导出、标记和详情按钮不使用图标；关闭抽屉等明确的工具操作可保留图标按钮。
- 交互状态：支持关键词、日期、状态、渠道组合查询；重置恢复默认值；列表覆盖空结果、分页、全选、批量导出和详情抽屉；演示数据明确标识。
- 组件实现：使用 Ant Design 官方 `Form`、`Input`、`Select`、`DatePicker.RangePicker`、`Button`、`Table`、`Pagination`、`Drawer`、`Descriptions`、`Tag` 和 `Empty`，由目标应用依赖或独立预览 UMD 运行时提供。
- 响应式：桌面展示完整导航和多列筛选；窄屏筛选器改为单列，表格保留横向滚动，详情抽屉占满可用宽度。
- 可访问性：所有输入具备 label，按钮保留键盘焦点，表格选择与详情操作提供 aria-label，抽屉支持 Esc 关闭并恢复焦点。
- 加载体验：预览依赖采用 `defer` 并行加载，内容插槽在依赖到达前显示轻量加载态，避免首屏空白；Shell 和页面挂载统一在 `DOMContentLoaded` 后执行。
- 偏离规范的理由：查询列表的控件采用 40px 高以保持信息密度；状态色仅表达订单状态，不替代品牌主操作色。
