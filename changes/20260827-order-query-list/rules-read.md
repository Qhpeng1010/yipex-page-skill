# Rules Read

- `DESIGN.md`：页面生成契约、组件库和默认 Shell 边界。
- `01-foundations.md`：YiPex 颜色、字体、字号、圆角、阴影、尺寸和间距 Token。
- `02-components.md`：输入框、按钮、复选框、Modal/Drawer 等控件规则。
- `03-query-list-patterns.md`：查询列表内容区、筛选网格、结果容器、标题和按钮默认规则。
- `execution/context-packs/layout.md`：后台页面内边距、布局和响应式约束。
- `execution/context-packs/accessibility.md`：键盘、触控面积、状态文本和响应式可读性。
- `execution/context-packs/components.md`：标准控件优先使用 Ant Design 官方组件及必要状态。
- `execution/context-packs/interaction.md`：进入、查询、成功、空结果、失败和恢复路径。
- `references/antd-component-map.md`：查询表单、表格、分页、抽屉、状态标签的官方组件映射。
- `shell/README.md`、`shell/shell.template.html`、`shell/shell.css`、`shell/shell-runtime.js`：固定 Shell 的结构、样式和运行时契约；本次内容区默认内边距为 24px。
- `shell/vendor/README.md` 及本地 vendor 资源：独立预览使用锁定的本地 React、Ant Design、dayjs 与图标依赖，避免 CDN 网络延迟。
