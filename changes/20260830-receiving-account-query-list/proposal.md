# Proposal

- 需求原文：帮我做一个收款账户列表，支持开户地、开户时间、开户币种、账户币种和商品类型筛选；列表展示开户信息，支持编辑、查看 15 项详情，并可提交申请收款账户。
- 页面目标：让平台运营人员快速筛选、查看和维护收款账户，并在同一列表上下文中提交新的收款账户申请。
- 使用角色：平台运营人员。
- 关键操作：查询、重置、申请收款账户、编辑账户、查看详情。
- 申请类型：新建收款订单（支持 SWIFT 电汇、覆盖全球银行网络、适合多币种跨境收款）；本地收款账户（使用指定国家/地区本地清算网络，到账快、费用低）。
- 申请信息：账户类型、账户持有人、开户地、开户行、账户币种、贸易国家/地区、商品大类、开户币种。
- 演示范围：未接入后端，数据通过浏览器本地存储演示；新申请默认进入“审核中”，并按开户时间倒序置顶。
