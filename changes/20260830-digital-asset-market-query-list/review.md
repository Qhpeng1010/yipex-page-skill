# Review

## 自动检查

- Page Spec V2 结构、Page Contract、组件、状态和交互映射通过。
- 标准查询列表预览构建通过，页面根节点和 JavaScript 轻量检查通过。
- 查询、重置和分页均已声明对应的触发、结果与恢复路径。
- 交易状态使用 Ant Design Badge 语义状态，并通过 Page Spec 显式映射。
- Shell 导航按需求裁剪为“首页、数字资产行情”，未展示无关目录。

## 功能覆盖

- 查询条件：币种关键词、资产类型、网络和交易状态。
- 列表字段：币种、资产名称、资产类型、网络、参考价格、24h 涨跌幅、交易状态和更新时间。
- 8 条演示数据支持筛选、重置和分页；所有价格与行情信息均明确为非实时演示数据。
- 页面覆盖 Loading、Empty、Error 和 Permission Denied 状态契约。

## 待人工验收

- 桌面和窄屏下的筛选布局、表格横向滚动与分页可达性。
- 查询、重置、组合筛选及空结果的实际浏览器交互体验。
- 业务方对数字资产分类、网络枚举和行情字段口径的确认。
