# Proposal

- 需求原文：生成订单管理 Tab 查询列表页面，提供五个状态 Tab、统一查询条件、订单列表、查看详情、取消订单和新增订单。
- 页面目标：帮助订单运营人员按状态快速定位订单，并在不丢失查询上下文的情况下完成详情查看和订单取消。
- 使用角色：订单运营人员。
- 关键操作：切换 Tab、查询、重置、分页、新增订单、查看详情、取消订单。
- 展示路由：8 项详情字段使用列表内 Drawer；6 项新增字段使用列表内 Modal；只有超过 16 项时才拆为独立详情页或表单页。
- 数据边界：全部行为使用浏览器内演示数据；新增和取消状态通过 localStorage 在当前浏览器中持久化。
