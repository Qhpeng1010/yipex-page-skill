# Review

## 自动检查

- Page Spec V2 结构、Contract、组件、状态和交互映射通过。
- 预览构建、设计记录派生和页面 JavaScript 轻量检查通过。
- 状态列使用 Page Spec 声明的 Ant Design Badge 语义色。

## 功能覆盖

- 六项查询条件：币种/类型、所属银行、所属国际地区、添加人、状态、时间。
- 列表字段：币种 ID、币种/类型、所属银行、所属国际地区、添加人、状态、时间和操作。
- 新增/编辑：大尺寸 Drawer，分为基础信息、归属信息、配置与状态，共 12 个表单项。
- 详情：大尺寸 Drawer，Descriptions 双列展示 15 个字段。
- 禁用：按当前状态控制可用性，执行前使用确认弹窗，成功后更新状态。
