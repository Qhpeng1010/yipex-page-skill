# Proposal

- 需求原文：创建一个新增结算规则页面，供财务运营人员配置商户结算规则。表单包含规则名称、适用商户、结算周期、手续费率、最低结算金额、生效时间、自动结算开关和备注。区分必填与选填字段，提供实时校验、未保存离开确认、提交 loading、提交失败和提交成功反馈。主操作为保存规则，次操作为取消；适配桌面和手机，使用演示数据，不虚构后端接口。
- 页面目标：帮助财务运营人员一次完成商户结算周期、费率、金额门槛与生效方式配置。
- 使用角色：财务运营人员。
- 关键操作：保存规则；取消并处理未保存内容。
- 数据边界：商户与周期均为演示数据，保存为本地模拟，不调用或声明后端接口。
