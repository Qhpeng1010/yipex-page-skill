## 页面概况

- 页面名称：新增结算规则
- 页面类型：settlement-rule-form
- 页面族：form
- Shell：yipex-default
- 信息密度：standard
- 原始需求：创建一个新增结算规则页面，供财务运营人员配置商户结算规则。表单包含规则名称、适用商户、结算周期、手续费率、最低结算金额、生效时间、自动结算开关和备注。区分必填与选填字段，提供实时校验、未保存离开确认、提交 loading、提交失败和提交成功反馈。主操作为保存规则，次操作为取消；适配桌面和手机，使用演示数据，不虚构后端接口。
