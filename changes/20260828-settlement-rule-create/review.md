# Review

## 自动检查

- Page Spec V2 结构、Page Contract、区域、操作、状态与交互映射：通过。
- `preview.html` 已由 `page-spec.json` 派生，包含 `#yipex-page` 根节点：通过。
- 页面内联 JavaScript 语法检查：通过。
- 预览依赖使用技能内锁定的 Ant Design、React、Day.js 与图标运行时：通过。
- 页面未声明或调用后端接口，提交仅为本地演示模拟：通过。

## 状态与交互覆盖

- 必填字段：规则名称、适用商户、结算周期、手续费率、最低结算金额、生效时间。
- 选填字段：自动结算、备注。
- 实时校验：必填、字符长度、首尾空格、数值范围、未来生效时间。
- 离开保护：取消、侧边导航和浏览器离开均覆盖未保存确认。
- 提交反馈：按钮 loading、页内失败 Alert、消息反馈、成功 Result。
- 演示失败态：将 `page.data.demoSubmission.mode` 改为 `failure` 后重新构建，或在预览地址添加 `?submit=failure`。
