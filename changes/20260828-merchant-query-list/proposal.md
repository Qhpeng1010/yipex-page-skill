# Proposal

- 需求原文：创建一个商户查询列表，供平台运营人员查找和管理商户。支持按商户名称、商户编号、经营状态、签约日期和所属行业筛选；结果表格展示商户名称、联系人、交易规模、经营状态、创建时间和负责人。支持重置、查询、分页、导出、批量选择和查看商户详情；详情使用右侧抽屉。使用演示数据，并覆盖 loading、empty、error 和 permission-denied 状态。
- 页面目标：帮助平台运营人员快速定位商户、判断经营规模、批量整理结果并核对详情。
- 使用角色：平台运营人员。
- 关键操作：查询、重置、分页、批量选择、导出、查看商户详情。
- 数据边界：全部查询与导出均作用于浏览器内演示数据，不调用或声明后端接口。
